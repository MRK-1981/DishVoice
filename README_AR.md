# DishVoice — مولّد فويس أوفر مصري محلي

هذه نسخة أولى من برنامج Desktop يعمل محليًا على Windows. النسخة المحمولة النهائية ستحتوي على `DishVoice.exe` وFFmpeg وصوت Piper داخل مجلد واحد؛ بعد فك الضغط لا تحتاج إلى تثبيت Python أو FFmpeg أو أي مكتبة.

## نقطة مهمة عن الأصوات المصرية

الصوت المرفق مبدئيًا هو `ar_JO-kareem-medium`، وهو عربي أردني، وليس مصريًا قاهريًا. لا أريد أن أسميه مصريًا وهو ليس كذلك. قائمة Piper الرسمية لا تحتوي حاليًا على صوت مصري قاهري رسمي. البرنامج مع ذلك لا يقفل على هذا الصوت: أي نموذج Piper متوافق بصيغة `.onnx` ومعه ملف `.onnx.json` يمكن إضافته إلى مجلد `voices` واختياره من الواجهة. راجع ترخيص كل نموذج قبل الاستخدام التجاري.

## المتطلبات على Windows

### تشغيل النسخة المحمولة

1. فك ضغط `DishVoice-Windows.zip`.
2. افتح مجلد `DishVoice`.
3. شغّل `DishVoice.exe`.
4. من خانة موديل Piper اختر الملف الموجود داخل `voices`، ثم الصق المشاهد واضغط التوليد.

لا تحتاج النسخة المحمولة إلى Python أو FFmpeg أو اتصال بالإنترنت أثناء التوليد.

### تشغيل نسخة التطوير من الكود

1. ثبّت Python 3.11 من الموقع الرسمي: https://www.python.org/downloads/windows/
   أثناء التثبيت فعّل اختيار **Add Python to PATH**.
2. ثبّت FFmpeg، وأضف مجلد `bin` إلى متغير Windows PATH. اختبر من PowerShell:

   ```powershell
   python --version
   ffmpeg -version
   ffprobe -version
   ```

3. نزّل مجلد المشروع إلى جهازك، ثم افتح PowerShell داخل المجلد:

   ```powershell
   cd C:\Path\To\dishvoice_desktop
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

   لو منع PowerShell تشغيل البيئة الافتراضية، نفّذ مرة واحدة في PowerShell عادي:

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

4. ضع نموذج الصوت وملف الإعداد بجانب بعضهما، مثل:

   ```text
   voices\ar_JO-kareem-medium.onnx
   voices\ar_JO-kareem-medium.onnx.json
   ```

   ملف `.json` لازم يكون له نفس اسم ملف `.onnx` مع إضافة `.json` في النهاية.
5. شغّل البرنامج:

   ```powershell
   python app.py
   ```

أو شغّل `run_windows.bat` بالنقر المزدوج؛ سيُنشئ البيئة الافتراضية ويثبت الحزم ثم يفتح البرنامج.

## تنسيق السكريبت

كل سطر يمثل مشهدًا مستقلًا:

```text
00:00 -> 00:07 | النص المنطوق في المشهد الأول
00:07 -> 00:17 | النص المنطوق في المشهد الثاني
```

يمكن استخدام `01:05` أو `00:01:05`. الأسطر التي تبدأ بـ `#` يتم تجاهلها.

عند التوليد، البرنامج:

- يرسل نص كل مشهد إلى Piper محليًا.
- يقيس طول الصوت الناتج.
- يبطئه أو يسرّعه بأقل قدر ممكن ليطابق مدة المشهد.
- يضيف صمتًا أو يقص الزيادة عند الحاجة.
- يدمج كل المشاهد في ملف WAV واحد.

## إضافة صوت جديد لاحقًا

ضع ملفي النموذج في مجلد `voices`:

```text
voices\my-egyptian-voice.onnx
voices\my-egyptian-voice.onnx.json
```

ثم افتح البرنامج واختر ملف `.onnx` الجديد. لا يكفي تغيير اسم الصوت أو اختيار لهجة من الواجهة؛ النموذج نفسه يجب أن يكون مدرّبًا على العربية المصرية، وإلا سيظل النطق غير مصري. يمكن إضافة أصوات مصرية جديدة لاحقًا إذا توفرت بنماذج ONNX وترخيص يسمح بإعادة التوزيع.

## الخطوة التالية في التطوير

إضافة قائمة أصوات بأسماء مفهومة، زر معاينة لكل صوت، تصدير MP3، واستيراد ملف توقيت من CSV أو SRT. وللوصول إلى عدة أصوات مصرية طبيعية فعلًا، نحتاج نماذج ONNX مصرية مرخّصة أو مرحلة تدريب/تحويل لأصوات مصرية؛ محرك Piper وحده لا ينشئ لهجة مصرية من دون نموذج مدرّب عليها.
