# DishVoice — مولّد فويس أوفر مصري قاهري

هذه نسخة Windows محمولة تعتمد على **VoiceTut-TTS**، وهو نموذج مخصص للعربية المصرية العامية، وليس Piper أو صوتًا أردنيًا. البرنامج يعرض 19 صوتًا مصريًا جاهزًا: أحمد، علي، حسن، كريم، محمود، محمد، مصطفى، رامي، شاكر، طارق، يحيى، يوسف، هدير، حنان، مريم، رنا، سارة، ياسمين، ويارا.

## ملاحظة مهمة قبل الاستخدام

ملف النموذج المصري حجمه حوالي **2.45 جيجابايت**، لذلك لا يتم نسخه داخل ملف الـEXE نفسه. عند أول ضغط على «توليد»، يحتاج البرنامج إلى اتصال بالإنترنت ليحمّل النموذج تلقائيًا من Hugging Face. بعد اكتمال التنزيل يُحفظ في كاش الجهاز ويُستخدم لاحقًا دون إعادة تنزيله. يجب أن يكون الجهاز متصلًا بالإنترنت في أول تشغيل، كما أن التوليد على CPU قد يكون بطيئًا مقارنة بكارت شاشة NVIDIA.

النموذج الرسمي: https://huggingface.co/mohammedaly22/VoiceTut-TTS
الترخيص: Apache-2.0.

## تشغيل النسخة المحمولة

1. فك ضغط `DishVoice-Windows-Egyptian-VoiceTut.zip`.
2. افتح مجلد `DishVoice`.
3. شغّل `DishVoice.exe`.
4. اختر الصوت المصري من القائمة.
5. ألصق المشاهد بالتوقيتات واضغط «توليد الفويس أوفر المصري».
6. في أول مرة انتظر تنزيل النموذج المصري، وقد يستغرق ذلك حسب سرعة الإنترنت ومساحة القرص.

لا تحتاج إلى تثبيت Python أو FFmpeg يدويًا؛ فهما مضمّنان في الحزمة. يلزم الإنترنت فقط لتنزيل نموذج VoiceTut أول مرة.

## تنسيق السكريبت

كل سطر يمثل مشهدًا مستقلًا:

```text
00:00 -> 00:07 | عمرك سألت نفسك: إزاي غسالة الأطباق بتغسل كل ده؟
00:07 -> 00:17 | الغسالات الحديثة بتستخدم تقريبًا من عشرة لخمستاشر لتر.
```

يمكن استخدام `01:05` أو `00:01:05`. الأسطر الفارغة والأسطر التي تبدأ بـ `#` يتم تجاهلها. البرنامج يولّد كل مشهد، يضبط سرعته ليلائم مدته، يضيف الصمت اللازم، ثم يدمج المشاهد في ملف WAV واحد.

## تشغيل نسخة التطوير

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install git+https://github.com/k2-fsa/OmniVoice.git
pip install -r requirements.txt
python app.py
```

## حدود النسخة

VoiceTut-TTS هو النموذج المصري الفعلي المستخدم في هذه النسخة، لكنه نموذج كبير؛ لذلك سرعة التوليد على جهاز بدون GPU قد تكون محدودة. الأصوات المتاحة هي الأصوات المدمجة في VoiceTut، ويمكن لاحقًا إضافة نماذج مصرية أخرى إذا كانت متوافقة ومرخّصة.
